## 📋 ПОЛНЫЙ ЧЕКЛИСТ (рекомендуется)

### 1. 🔤 ТИПОГРАФИКА И КОНТЕНТ

#### Заголовки

- [ ] H1 уникален и описывает содержание страницы
- [ ] Только один H1 на странице
- [ ] Иерархия заголовков: H1 → H2 → H3 (без пропусков)
- [ ] Заголовки не заканчиваются на знаки препинания (кроме ? и !)
- [ ] Длина title в metadata: 50-60 символов (оптимально для SEO)

#### Текст

- [ ] Описание (description): 150-300 символов
- [ ] Текст читаем — нет опечаток, грамматических ошибок
- [ ] Язык текста: русский (если не иное)
- [ ] Цифры отформатированы правильно (25 000 ₽ не 25000руб)
- [ ] Нет "воды" — каждый абзац несёт пользу

#### Изображения

- [ ] Все изображения имеют описательный alt-текст
- [ ] Изображения оптимизированы (WebP формат предпочтителен)
- [ ] Указаны размеры или aspect-ratio (предотвращает CLS)
- [ ] `loading="lazy"` для изображений ниже fold
- [ ] OG изображение для social sharing (1200x630px)

---

### 2. 🎨 ДИЗАЙН И ВИЗУАЛ

#### Цвета

- [ ] Используются ТОЛЬКО цвета из DESIGN-SYSTEM.md
- [ ] Нет inline styles с цветами (`style={{ color: "#fff" }}`)
- [ ] Контраст текста минимум 4.5:1 (для нормального текста)
- [ ] Акцентный цвет: amber (не синий, не красный!)

#### Отступы и Раскладка

- [ ] Контент центрирован в container (`container mx-auto px-4...`)
- [ ] Отступы между секциями: py-16 md:py-24 (стандарт)
- [ ] Gap в сетках: gap-6 lg:gap-8 (стандарт)
- [ ] Padding в карточках: p-6 md:p-8 (стандарт)

#### Компоненты

- [ ] Используются готовые компоненты из COMPONENTS-CATALOG.md
- [ ] Карточки имеют hover эффект (shadow/translate)
- [ ] Кнопки имеют состояния (hover, focus, disabled)
- [ ] Формы валидируются (react-hook-form + zod)

#### Анимации

- [ ] Важные секции обёрнуты в InViewWrapper
- [ ] Анимации не мешают пользователю (можно отключить?)
- [ ] Длительность анимаций: 200-700ms (не дольше!)

### 3. 📱 АДАПТИВНОСТЬ (RESPONSIVE)

#### Mobile First

- [ ] Сначала стили для mobile, потом @media для desktop
- [ ] Проверено на 375px (iPhone SE / маленький мобильный)
- [ ] Проверено на 768px (планшет)
- [ ] Проверено на 1024px+ (десктоп)

#### Мобильные особенности

- [ ] Touch targets минимум 44x44px
- [ ] Текст читаем на mobile (min 16px для основного текста)
- [ ] Горизонтальный скролл отсутствует
- [ ] Меню адаптировано (гамбургер на mobile)
- [ ] Изображения не выходят за границы экрана

### 4. ♿ ДОСТУПНОСТЬ (ACCESSIBILITY)

- [ ] Используются семантические теги (main, section, nav, article)

## 🚨 COMMON ISSUES (частые проблемы)

| Проблема                | Решение                                   |
| ----------------------- | ----------------------------------------- |
| Build падает            | Проверьте TypeScript ошибки, импорты      |
| Белая страница          | Проверьте ErrorBoundary, консоль браузера |
| Стили не применяются    | Проверьте Tailwind классы, импорт css     |
| Mobile сломан           | Проверьте overflow, фиксированную ширину  |
| Изображения не грузятся | Проверьте пути, public folder             |
| Форма не отправляет     | Проверьте API route, CORS                 |

## ✅ ГОТОВО К КОМИТУ?

Если ВСЕ пункты из **Быстрого чеклиста** выполнены:

```bash
# 1. Запустите финальную проверку
bun run pre-deploy:quick

# 2. Зафиксируйте изменения
git add -A
git commit -m "type: описание изменений"

# 3. Push (pre-push хук проверит ещё раз!)
git push
```

### Conventional Commits форматы:

```
feat:     новая функция
fix:      исправление бага
page:     обновление страницы /url
design:   изменение дизайна
style:    форматирование кода (не меняет логику)
refactor: рефакторинг (не меняет функционал)
docs:     документation
chore:    вспомогательные изменения (deps, config)
test:     тесты
perf:     производительность
```

Примеры:

- `feat: добавить форму обратной связи`
- `fix: исправить мобильное меню на 375px`
- `page: обновить страницу /events/svadba`
- `design: изменить цвет CTA кнопок на amber`
- `chore: обновить зависимости`
